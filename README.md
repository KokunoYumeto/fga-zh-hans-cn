# FGA 简体中文版：格罗滕迪克《代数几何基础》（Fondements de la géométrie algébrique）

本仓库是亚历山大·格罗滕迪克（Alexander Grothendieck）《代数几何基础》（*Fondements de la géométrie
algébrique*，简称 FGA）的完整简体中文译本：1957–1962 年布尔巴基讨论班（Séminaire Bourbaki）第 149、182、190、
195、212、221、232、236 次报告，各篇报告的勘误与补充，以及 1962 年的评论。

## 制作方式

中文翻译、校订、编辑和排版由人工智能完成，工作记录为 OpenAI Codex 的 GPT-5.6 Sol 与 GPT-6 Astra（Ultra 推理
强度）。译文以法文原文为主要依据，本项目维护的英文版（[fga-en](https://github.com/KokunoYumeto/fga-en)）作为次要
参照（见“来源与署名”）。原文页码保留在页边。

## 状态

全书已译完。译文中可能仍有错误。
