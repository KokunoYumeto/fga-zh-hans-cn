# Unofficial FGA in Simplified Chinese / 非官方 FGA 简体中文版

This repository is the canonical publication lineage for the independent,
unofficial mainland Simplified-Chinese (`zh-Hans-CN`) edition of Alexandre
Grothendieck's *Fondements de la géométrie algébrique* (FGA).

Canonical Zenodo lineage: concept DOI
[10.5281/zenodo.22132590](https://doi.org/10.5281/zenodo.22132590); this release:
[10.5281/zenodo.22132591](https://doi.org/10.5281/zenodo.22132591).

The first release contains all eight Séminaire Bourbaki Exposés 149, 182, 190,
195, 212, 221, 232, and 236; the 1962 *Commentaires*; and all eight linked
errata through the end of the erratum to Exposé 236.

## Staged release

- Reader: [`fga-zh-hans-cn.pdf`](releases/2026-08-27-fga-complete/fga-zh-hans-cn.pdf)
- Editable source and compact evidence: [`fga-zh-hans-cn-source.zip`](releases/2026-08-27-fga-complete/fga-zh-hans-cn-source.zip)
- Exact inventory, provenance, rights, and QA: [`releases/2026-08-27-fga-complete/`](releases/2026-08-27-fga-complete/)

The 148-page reader passed source and witness replay, structural and formula
checks, deterministic XeLaTeX convergence, font and glyph checks, text
extraction, internal-link validation, archive-member verification, privacy
review, and bounded visual inspection. Its status is producer-complete and
mechanically/visually verified, but not independently certified for Chinese
prose.

## Historical provenance

The Chinese edition was first preserved inside the shared French/English/Chinese
record [10.5281/zenodo.22083916](https://doi.org/10.5281/zenodo.22083916).
That immutable multilingual record remains historical parent provenance. This
repository starts a distinct language-specific GitHub and Zenodo concept
lineage; it is not a successor version in the multilingual concept.

## Rights and non-endorsement

This is an independent scholarly translation and typesetting project. It is not
an official edition and does not imply endorsement by the historical author,
the Séminaire Bourbaki, NUMDAM, a publisher, or any institution. NUMDAM scans
and French/English witness files are excluded. No new blanket public-domain or
open-license claim is made over the underlying FGA text. See the
release-specific [`RIGHTS.md`](releases/2026-08-27-fga-complete/RIGHTS.md).
